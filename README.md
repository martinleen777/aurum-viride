# Aurum Viride — сайт издательства

Сайт: **https://aurumviride.com** (размещён бесплатно на GitHub Pages).

Сайт состоит из обычных файлов, ничего собирать не нужно: изменили файл на GitHub — через 1–2 минуты изменения появились на сайте.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `data/books.js` | **Все книги, журналы и контакты.** Это главный файл, который вы будете менять. |
| `index.html` | Главная страница (тексты приветствия) |
| `books.html` | Каталог книг (заголовок и подзаголовок) |
| `journals.html` | Страница журналов |
| `about.html` | «О нас» (тексты об издательстве) |
| `item.html` | Страница одной книги или журнала — одна на всех, заполняется сама из `data/books.js` |
| `images/covers/` | Папка для картинок обложек |
| `assets/` | Оформление и программный код — обычно трогать не нужно |
| `CNAME` | Адрес сайта `aurumviride.com` — не удалять |

## Как редактировать файлы прямо на GitHub

1. Откройте репозиторий на github.com и нажмите на нужный файл, например `data/books.js`.
2. Нажмите значок карандаша ✏️ (Edit this file) справа вверху.
3. Внесите изменения.
4. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.
5. Через 1–2 минуты обновите сайт (если не видно изменений — Ctrl+F5 или обновить страницу на телефоне).

## Как добавить книгу

Откройте `data/books.js`, найдите раздел `BOOKS: [`. Каждая книга — это блок в фигурных скобках `{ ... }`.

1. Скопируйте один блок целиком — от `{` до `},`.
2. Вставьте его сразу после последнего блока книги (перед `]`).
3. Поменяйте значения в кавычках:

```js
    {
      id: "sad-alhimika",            // уникальное имя латиницей, без пробелов — будет в адресе страницы
      title: "Сад алхимика",         // название
      subtitle: "Повесть",           // подзаголовок (можно оставить "")
      author: "Анна Иванова",
      year: 2026,                    // год — без кавычек
      genre: "Художественная проза", // по жанрам работает фильтр в каталоге
      pages: 240,
      format: "130×200 мм, твёрдый переплёт",
      isbn: "978-5-000000-00-0",
      cover: "images/covers/sad-alhimika.jpg", // картинка обложки, или "" для рисованной
      color: "emerald",              // цвет рисованной обложки
      amazon_url: "https://www.amazon.com/dp/...",  // ссылка на Amazon, или "" — кнопки не будет
      apple_books_url: "https://books.apple.com/...", // ссылка на Apple Books, или "" — кнопки не будет
      short: "Одна-две строки для карточки в каталоге.",
      description: [
        "Первый абзац полного описания.",
        "Второй абзац."
      ]
    },
```

**Важно:**
- После каждого блока `{ ... }` ставится запятая `,`.
- Текст — всегда в прямых кавычках `"..."`. Если внутри текста нужны кавычки, используйте «ёлочки».
- `id` не должен повторяться.
- Пример-заглушку удаляйте целиком — весь блок от `{` до `},`.
- Кнопки «Купить на Amazon» и «Читать в Apple Books» появляются на странице книги, только если заполнены `amazon_url` / `apple_books_url`. Ссылку берите из адресной строки браузера на странице книги в Amazon или Apple Books.
- Строка `example: true` включает жёлтую плашку «Пример — заменить». У настоящих книг этой строки быть не должно.

Журнал добавляется точно так же в раздел `JOURNALS: [`. У журнала вместо автора и жанра — `issue` (номер выпуска), `topic` (тематика), и есть необязательный список `contents` (содержание номера).

Порядок на сайте — по году, новые сначала. На главной показываются три самые новые книги и два журнала.

## Как добавить обложку

Без картинки сайт рисует аккуратную обложку сам — с названием, автором и цветом из поля `color`
(варианты: `emerald`, `forest`, `olive`, `teal`, `gold`, `wine`, `ink`).

Чтобы поставить настоящую обложку:

1. Подготовьте картинку в формате JPG или PNG, пропорции 2:3 (например 800×1200 пикселей), размер желательно до 300 КБ.
2. Назовите файл латиницей без пробелов, например `sad-alhimika.jpg`.
3. На GitHub откройте папку `images/covers`, нажмите **Add file → Upload files**, перетащите файл и нажмите **Commit changes**.
4. В `data/books.js` у этой книги впишите: `cover: "images/covers/sad-alhimika.jpg",`

## Как поменять тексты

- **Контакты** (почта, телефон, адрес, часы работы, соцсети) — в начале `data/books.js`, раздел `SITE`. Они сразу обновятся и в подвале всех страниц, и на странице «О нас».
- **Тексты главной** — `index.html`: заголовок «Книги, которые хочется хранить», абзац под ним, цитата и короткий текст внизу.
- **Об издательстве** — `about.html`.
- **Заголовки каталога и журналов** — `books.html` и `journals.html`.

В HTML-файлах меняйте только текст между тегами, например в `<p>Здесь текст</p>` — только «Здесь текст». Значки `<` `>` и всё, что внутри них, лучше не трогать.

Пункты меню — в начале файла `assets/site.js` (список `NAV`).

## Посмотреть сайт у себя на компьютере

Скачайте репозиторий (**Code → Download ZIP**), распакуйте и откройте файл `index.html` двойным щелчком — сайт откроется в браузере. Можно править файлы и обновлять страницу.

## Хостинг и домен (делается один раз)

1. **GitHub → Settings → Pages**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`, Save.
2. Там же **Custom domain**: `aurumviride.com`, Save. Когда проверка DNS пройдёт, включите **Enforce HTTPS**.
3. **GoDaddy → DNS** домена `aurumviride.com`:
   - четыре записи типа **A**, имя `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (старые A-записи для `@` удалить);
   - запись **CNAME**, имя `www`, значение `martinleen777.github.io`.

DNS обновляется от нескольких минут до суток.
